# Security

This is a community documentation / learning package. It is **not** an official Cardano, Mesh, Aiken, Orcfax, or Midnight product.

## How to report a problem

- **Docs mistakes, broken links, unclear scope:** open a normal GitHub issue (no secrets).
- **Something that could put funds or keys at risk:** do **not** post details in a public issue. Email the maintainer contact listed in the repo (or use GitHub Security Advisories when enabled) and wait for a reply before disclosing publicly.

## Never paste into issues or PRs

- Seed phrases, private keys, mnemonic backups
- Wallet `.env` files, payment signing keys, API secrets
- Mainnet addresses with meaningful balances tied to a vulnerability write-up
